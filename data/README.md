Generated by `./run.sh data`:

- `city.json`: the synthetic city (nodes, walk/transit/car edges, transit lines, POIs, hotels, zones)
- `history.csv.gz`: 120 days of background arrivals per POI per 15-minute slot (the Bayesian network's training data)
- `transit_history.csv`: delays per line and time-of-day block

A real city can replace these files if it follows the same schema.
